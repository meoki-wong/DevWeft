# B04 — 依赖与公共默认值

## 交付

- 新增 [`docs/DEPENDENCIES.md`](../DEPENDENCIES.md)，说明运行依赖、开发依赖和 Windows 本机 PostgreSQL 可选依赖的用途。
- 将只用于 PostgreSQL 契约测试的 PGlite 移至开发依赖；把 Vitest 与 coverage provider 更新到 5.0.4、happy-dom 更新到 21.0.1，并加入 YAML 解析器用于 OpenAPI 检查。声明 Node.js `>=22.12.0`，与 Vitest 要求和部署文档对齐。
- 删除未连接任何 provider、且只被单个测试引用的 Mock MR client；移除测试提交中的空 `mr` 字段、未使用的 MR 审批 OpenAPI schema 和 promotion API 中 MR 状态字段。
- 新增 SQLite/PG v42 迁移，删除 `promotion_proposals` 中无调用方的五个 MR 元数据列；重新生成 PostgreSQL baseline，记录版本 43。
- Git remote 注册与 bootstrap 默认 provider 为 `generic`，显式 provider 仍可指定。默认共享规则改为跨团队工程约定，规则数从实际规则数量生成。
- 泛化 replay/gate/branch 代码注释中 GitLab 专有假设。

## 验证

- 定向测试覆盖公开默认规则、generic/GitHub provider、迁移、PG baseline、备份恢复和 OpenAPI：6 个文件、48 项通过。
- 升级 Vitest 后补齐两处未等待的异步断言；对应账本文件 13 项通过。
- `npm run verify:release -- --audit`：133 个测试文件通过，1109 项通过、6 项跳过；本地发布门禁通过。
- 发布门禁解析 23 个 JSON 文件和 OpenAPI YAML，检查 lockfile、运行依赖树、四个 CMD 入口以及品牌/流水线/MR client 残留。
- `npm audit --omit=dev --audit-level=high` 未发现高危或严重项；当前有 1 个上游中危 advisory（审计展开为 `@open-policy-agent/opa-wasm` 与其 `sprintf-js` 依赖两项），`sprintf-js` 暂无已发布修复版本。依赖清单保留了复查要求。

## 限制与后续

- PGlite/PGlite baseline 验证不代表真实 PostgreSQL 服务部署已通过。
- npm 审计需要联网；`npm run verify:release` 默认离线运行，发布前使用 `npm run verify:release -- --audit`。
- `business_snapshots` 的旧 MR merge 快照字段属于历史 schema，目前不被运行时代码引用；本工作包只移除已确认闲置的 promotion proposal 元数据，以免不必要地重建既有快照表。
