# F06 — Reproducible evidence package

## Delivered

- Added `GET /api/testing/runs/{runId}/evidence-pack` and a download action in the run evidence dialog.
- Produces a deterministic ZIP with run/config/version metadata, a digest-only locked case list, allowlisted checks, redacted attempt summaries, and artifact hashes/state.
- Excludes raw report bodies, source files, raw log bodies, raw artifact archives, environment variables, and secret references.
- Adds `node scripts/verify-evidence-pack.mjs --file <path>` to validate exact ZIP entry membership, safe paths, byte sizes, and SHA-256 values against `manifest.json`.
- Added [EVIDENCE-PACK.md](../EVIDENCE-PACK.md) with format and integrity semantics.

## Design decisions

- The evidence package is deterministic for identical recorded run data. The generated timestamp is the immutable run finish time, not export time.
- Only allowlisted fields are copied from report and attempt rows. Test sources and arbitrary report details are not exported.
- The manifest hashes every payload file. The ZIP CRC and SHA checks detect corruption; they do not independently prove the original test result or sign the package.

## Verification

- `npx vitest run test/evidence-pack.test.mjs test/cloud-testing-evidence.test.mjs test/dashboard-testing-read.test.mjs --reporter=dot` — 3 files, 64 tests passed.
- Tests verify deterministic bytes, sensitive/source exclusion, file hashes, tamper rejection, unlisted-entry rejection, and missing-run behavior.
- `node --check testing/evidence-pack.js`, `node --check scripts/verify-evidence-pack.mjs`, and `node --check public/assets/cloud-testing/evidence-dialog.js` passed.

## Limits

- The evidence pack includes referenced artifact hashes but not raw artifact bytes or source code, so it is not a self-contained environment reconstruction.
- Only local SQLite fixtures and the browser DOM harness were exercised; production database and HTTP download paths need deployment validation.
