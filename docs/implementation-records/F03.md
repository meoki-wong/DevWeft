# F03 — Decision explain

## Delivered

- Added `GET /v1/test-runs/{runId}/explain`, protected by repository `read_result` permission, and MCP tool `awp_test_explain`.
- The response is read-only and uses the run's stored lane, run-group required units, immutable suite lock, referenced suite revisions, bound execution profile, runner image, and policy revision.
- Stable reason codes explain where each value came from: `VALUE_FROZEN_ON_RUN`, `REQUIRED_BY_RUN_GROUP`, `LOCKED_IN_SUITE_PLAN`, `MATCHED_RUN_UNIT_AND_SIDE`, `FILTERED_BY_RUN_UNIT_AND_SIDE`, `PROFILE_FROZEN_BY_BINDING`, `IMAGE_FROZEN_BY_BINDING`, and `POLICY_FROZEN_BY_BINDING`.
- Returns both `lockedCases` and the unit/side-filtered `selectedCases`. The filtering uses the same `filterCasesForUnit` function as the Guest Agent. Case provenance includes layer, overlay, revision, and content digest.
- Profile output is allowlisted to revision identity, timeouts, and network policy ID; secret references and other profile fields are omitted. The runner image reports the binding digest and current row digest so drift is visible.
- Added `RUN_NOT_FOUND` to the API error contract, an OpenAPI operation, a 37-tool inventory, and [DECISION-EXPLAIN.md](../DECISION-EXPLAIN.md).
- Capped the release gate at four Vitest workers after an unbounded run caused both PGlite suites to hit their 60-second setup timeout; the same suites passed when rerun alone and in the capped full run.

## Verification

- Targeted: `npx vitest run test/testing-m2.test.mjs test/contracts.test.mjs test/docs-freshness.test.mjs test/server-api.test.mjs test/api-contract.test.mjs` — 5 files and 30 tests passed.
- Release gate: `npm run verify:release` — 142 test files passed, 1,162 tests passed, 6 skipped; all contract, dependency, residue, and test checks passed.
- The explanation test verifies exact selected cases, excluded smoke cases, cross-repository rejection, and that the run remains queued after the read-only service call. REST verifies the success envelope and `RUN_NOT_FOUND` status.
- `node --check` passed for `testing/explain.js`, `testing/routes.js`, and `tools/test-run.js`.

## Limits

- SQLite and the local test fixtures were exercised; the explanation query was not run against a real PostgreSQL deployment.
- The endpoint explains recorded provenance. It does not reconstruct an earlier planner heuristic that was not stored.
- The latest release gate skipped the optional network audit and environment-guarded PostgreSQL/Playwright/Chromium tests.
