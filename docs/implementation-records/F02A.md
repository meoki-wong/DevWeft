# F02A — Local process runner

## Delivered

- Added a local runner backend selected with `AWP_RUNNER_BACKEND=local`; Hyper-V remains the default backend when `AWP_HYPERV_ENABLED=true`.
- The worker claims `static` runs only in local mode. `smoke` work remains queued for a backend that supports it.
- The local lane accepts a normal lease and signed runSpec, executes the Guest Agent as a child Node process, then uses the existing signed sidecar, artifact preparation/upload, and `completeLease` path.
- Each local check records `backend: local-process` and `isolation: host-process`; the artifact also includes an execution-mode marker. Readiness reports `node.executionMode=local-process`.
- The process runner uses argv with `shell:false`, keeps bounded stdout/stderr tails (64 KiB per stream by default), saves both logs, preserves exit codes, and produces stable `passed`, `failed`, `error`, `timed_out`, or `canceled` states.
- Timeouts and cancellation stop the process tree (POSIX process group; Windows `taskkill /T /F`). Worker shutdown and lease cancellation abort local execution. A canceled lease is recorded as canceled instead of being requeued.
- The backend does not provide VM isolation and does not inject run secrets. It must only execute trusted repository code.
- Added `npm run worker` for direct local worker startup. PM2 also starts the worker when local mode is configured.

## Limits and follow-up

- The integrated execution was exercised on macOS with SQLite. Windows process-tree termination, Linux behavior, PostgreSQL, and PM2 deployment were not run on real target hosts.
- A local process runs with the worker account's filesystem and network permissions. Use Hyper-V for untrusted code.
- Static-only support is intentional. A local worker does not consume smoke runs and does not inject secrets.
- The default release gate omits network audit. The opt-in gate now audits the full runtime and development dependency graph; its 2026-10-15 run reported only the documented moderate `opa-wasm → sprintf-js` advisory and no high/critical advisories.
